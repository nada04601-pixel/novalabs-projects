# 티스토리 연재 원고: 노바랩 공작소 도구 묶음 소개

노바랩 공작소(novalabs.co.kr)의 계산기·도구를 **상황별로 묶어** 소개하는 티스토리 글 원고입니다.
도구 하나씩 홍보하기보다 "퇴사할 때", "이사할 때"처럼 독자가 실제로 검색하는 상황을 주제로 잡고,
글 안에서 정보를 충분히 준 다음 필요한 계산을 사이트로 연결하는 구성입니다.

"올려도 되는 날"은 글에서 링크한 사이트 가이드 글의 공개일 기준입니다. 사이트 가이드는 예약 공개(`src/data/guides.ts`의 `date`)라
그 날짜 전에는 링크가 404가 됩니다. 1~6과 8은 이미 공개된 글과 도구 페이지만 연결했습니다.

일주일에 2~3편 정도로 나눠 올리는 것을 권합니다. 같은 날 여러 편을 올리면 티스토리·네이버 모두 노출에 불리합니다.

## 티스토리에 올리는 방법

원고마다 `.md`(마크다운 모드용)와 `.html`(HTML 모드용) 두 가지가 있습니다. 계산기 안내 상자·표 색·도구 카드 같은 꾸밈이 들어간 **`.html`을 권장**합니다.

**HTML 모드로 올릴 때**
1. 글쓰기 → 오른쪽 위 `기본모드`를 **`HTML`**로 바꿉니다.
2. `.html` 파일에서 맨 위 안내 주석(`<!-- ... -->`) 아래 `<div ...>`부터 끝까지 붙여넣습니다.
3. `기본모드`로 돌아와 미리보기로 확인합니다.

`.md`를 고쳤다면 `node blog/tistory/md-to-html.mjs blog/tistory/02-resignation-money.md`처럼 실행해 `.html`을 다시 만드세요.
(01번 `.html`은 손으로 만든 것이라 주의 상자가 하나 더 있습니다. 01번을 다시 생성하면 그 상자는 빠집니다.)

**대표 이미지(썸네일)**
`thumbnails/` 폴더에 원고 번호와 같은 이름의 PNG(1200×750, 16:10 가로형)가 있습니다. 글쓰기 화면에서 이미지를 본문에 넣고 '대표 이미지'로 지정하세요.
대표 이미지는 화면마다 다르게 잘립니다(티스토리 목록 카드 약 1.6:1, 다음·네이버 검색 결과는 가운데 정사각형, 카카오톡 링크 미리보기 1.91:1).
그래서 글자는 모두 가운데 정사각형 안에 가운데 정렬로 넣고 양옆에는 잘려도 되는 색 띠만 두었습니다. 주제 태그와 후킹 문구(한 줄 7~8자, 세 줄)만 넣었고, 글 제목은 목록·검색 결과에 따로 나옵니다.
문구를 고치려면 `thumbnails/make-thumbnails.mjs`의 `POSTS`의 `hook`(두 줄, `**굵게**`는 강조색)을 고친 뒤 `node blog/tistory/thumbnails/make-thumbnails.mjs`를 실행하세요
(번호를 붙이면 그 글만: `... make-thumbnails.mjs 05`).

**마크다운 모드로 올릴 때**

1. 글쓰기 → 오른쪽 위 `기본모드` 를 **`마크다운`** 으로 바꿉니다.
2. 원고 파일에서 `<!-- 본문 시작 -->` 아래부터 `<!-- 본문 끝 -->` 위까지 복사해 붙여넣습니다.
3. 제목·태그·카테고리는 파일 맨 위 "올리기 정보"에 적어 둔 값을 씁니다.
4. 대표 이미지는 사이트 화면 캡처(해당 계산기 결과 화면)를 한 장 넣으면 클릭률이 좋아집니다.
   캡처에 실제 개인 정보(이름, 실제 급여 등)가 보이지 않게 예시 값으로 계산한 화면을 쓰세요.
5. 발행 전 미리보기에서 링크가 모두 열리는지 눌러 확인합니다.

## 홍보 효과를 높이는 운영 원칙

- **사이트 가이드 글을 그대로 옮기지 않기.** 같은 문장이 두 곳에 있으면 검색엔진이 중복 문서로 보고 둘 중 하나만 노출합니다.
  원고는 사이트 가이드와 겹치지 않게 새로 썼고, 자세한 설명은 사이트 가이드로 넘기는 구조입니다. 고쳐 쓸 때도 이 원칙을 지켜 주세요.
- **링크는 설명 뒤에.** 각 도구 링크는 그 도구가 필요한 이유를 설명한 문단 바로 뒤에 두고, 글 끝 "함께 보면 좋은 도구"에 한 번 더 모읍니다.
  설명 없이 링크만 나열한 글은 저품질로 분류되기 쉬우니, 고쳐 쓸 때도 링크 수보다 본문 정보량을 먼저 챙기세요.
- **사이트 운영자라는 사실을 밝히기.** 원고마다 "제가 만든 사이트"라고 적어 두었습니다. 숨기는 것보다 신뢰를 얻고, 광고성 글로 신고될 위험도 줄어듭니다.
- **숫자는 사이트 계산기 결과와 맞추기.** 원고의 예시 금액은 사이트 계산 코드(`src/lib/calculators/`)로 2026년 요율 기준으로 계산한 값입니다.
  내년에 요율(`src/data/rates/`)이 바뀌면 글의 예시도 함께 고치고 "2027년 기준"으로 제목을 갱신하면 다시 검색에 걸립니다.
- **사이트 링크는 글 하나에 5개 안팎.** 같은 도구 링크를 본문과 글 끝에 두 번 걸지 않습니다. 6~10번은 이 기준으로 줄였습니다
  (본문 안내 상자의 도구 링크만 남기고 "함께 보면 좋은 도구" 카드·정리 표의 링크와 가이드 안내 링크 일부를 뺌, 10번 허브 글의 도구 목록은 이름만).
  블로그 전체가 홍보용으로 보이지 않도록 링크가 없거나 1개뿐인 일반 정보글을 사이사이 섞어 올리는 것도 권합니다.
- **티스토리 글끼리도 연결하기.** 연재가 쌓이면 각 글 끝에 같은 연재의 다른 글 링크를 1~2개씩 추가하세요(예: 퇴사 글 ↔ 연말정산 글).
- **유입 확인.** 사이트에 방문 분석 도구가 아직 없어서 링크에 UTM 값은 붙이지 않았습니다. 대신 티스토리 통계의 "유입 경로"와
  구글 Search Console·네이버 서치어드바이저의 "외부 링크/유입" 항목으로 효과를 확인할 수 있습니다.
