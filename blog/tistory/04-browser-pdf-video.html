서류를 내려고 하면 꼭 이런 일이 생깁니다.

  • "첨부 파일은 10MB 이하로 올려 주세요" → 스캔한 PDF가 25MB
  • "서류는 하나의 PDF로 합쳐서 제출" → 파일이 다섯 개
  • "회의 녹화본 공유해 주세요" → 메신저가 용량 초과로 안 보내짐

이럴 때 프로그램을 설치하거나, 계약서·증명서 같은 서류를 정체 모를 사이트에 올리기는 꺼려지죠. 그래서 제가 만든 사이트 노바랩 공작소에는 파일을 서버로 보내지 않고 지금 쓰는 브라우저 안에서만 처리하는 도구들을 모아 두었습니다. 페이지를 닫으면 파일은 브라우저 메모리에서도 사라지고, 회원가입도 필요 없습니다.

상황별로 어떤 도구를 어떤 순서로 쓰면 되는지 정리해 볼게요.

상황 1. 서류 여러 장을 PDF 하나로 제출해야 할 때

입사 서류, 장학금 신청, 연말정산 증빙처럼 "한 파일로" 내라는 경우가 많습니다. 이 순서로 하면 깔끔합니다.

  1. 종이 서류 사진 → PDF: 휴대폰으로 찍은 사진을 이미지를 PDF로에서 한 파일로 묶습니다.
  2. PDF 여러 개 → 하나로: 받은 PDF들과 1번 파일을 PDF 합치기에서 제출 순서대로 합칩니다.
  3. 거꾸로 들어간 쪽, 빈 쪽 정리: PDF 페이지 정리에서 미리보기를 보며 회전·순서 변경·삭제를 합니다.
  4. 용량 제한 맞추기: 마지막으로 PDF 용량 줄이기로 압축합니다.

순서가 중요한 이유가 있어요. 합치기는 원본을 그대로 이어 붙이기 때문에 용량이 줄지 않습니다. 그래서 압축은 맨 마지막에 한 번만 하는 게 좋습니다.

사진을 찍을 때는 그림자가 지지 않게 밝은 곳에서, 서류가 화면을 꽉 채우게 찍으면 PDF로 바꿨을 때 글자가 훨씬 잘 보입니다. 사진·PDF 변환 때 알아 둘 점은 사진을 PDF로, PDF를 사진으로 글에 정리해 두었습니다.

상황 2. PDF가 너무 커서 첨부가 안 될 때

PDF가 큰 이유는 대부분 안에 들어 있는 이미지 때문입니다. 스캔본이나 사진을 묶은 PDF는 쪽마다 고해상도 사진이 들어 있어서 금방 수십 MB가 됩니다.

  • 스캔·사진 위주 PDF → 압축 효과가 큽니다.
  • 워드·한글에서 바로 저장한 글자 위주 PDF → 이미 작아서 압축해도 별로 줄지 않거나 오히려 커질 수 있습니다. 이럴 땐 '가볍게'를 쓰거나 원본을 그대로 내세요.
  • 전자서명이 들어간 PDF는 압축하면 서명이 무효가 됩니다. 서명된 문서는 원본을 제출하세요.

그래도 용량을 못 맞추면 PDF 나누기로 파일을 두세 개로 나눠 보내는 방법도 있습니다. PDF가 커지는 원리는 PDF 용량 줄이는 방법 글에 더 자세히 적어 두었습니다.

상황 3. 두꺼운 PDF에서 몇 쪽만 보내고 싶을 때

100쪽짜리 자료에서 5~7쪽만 필요할 때는 PDF 나누기·페이지 추출에 5-7처럼 쪽 범위만 넣으면 됩니다. 반대로 PDF의 한 쪽을 단톡방이나 SNS에 이미지로 올리고 싶다면 PDF를 이미지로를 쓰세요. 쪽마다 JPG·PNG로 바뀝니다.

합치기·나누기·정리를 언제 무엇으로 하면 되는지는 PDF 합치기·나누기·페이지 정리 상황별 정리에서 한 번에 볼 수 있습니다.

상황 4. 동영상이 메신저로 안 보내질 때

휴대폰으로 찍은 영상은 1분만 넘어도 수백 MB가 되곤 합니다.

  • 필요한 부분만: 동영상 자르기로 앞뒤를 잘라 길이부터 줄입니다.
  • 용량 줄이기: 동영상 용량 줄이기로 해상도와 비트레이트를 낮춥니다. 휴대폰 화면으로 볼 영상이라면 화질 차이가 거의 느껴지지 않습니다.
  • 소리만 필요할 때: 강의·회의 녹화본은 동영상 MP3 추출로 음성만 뽑아 두면 출퇴근길에 듣기 좋습니다.

자르기 → 압축 순서로 하면 처리 시간도 짧아집니다.

상황 5. 블로그에 넣을 움짤(GIF)을 만들 때

블로그를 하다 보면 앱 사용법이나 요리 과정처럼 짧게 반복되는 장면을 보여 주고 싶을 때가 있습니다. 동영상 GIF 변환에서 3~5초 구간을 골라 GIF로 만들면 됩니다.

GIF는 용량이 금방 커지니 이렇게 줄여 보세요.

  • 구간을 짧게 (가장 효과가 큼)
  • 가로 크기를 480px → 320px로 (용량이 절반 아래로)
  • 초당 프레임(fps)을 낮게

다른 사람이 만든 사진·영상·음악은 사용 권한이 있을 때만 편집하고 올려 주세요. 특히 워터마크는 저작권자 표시라서, 권한 없이 지우고 쓰면 저작권 침해가 될 수 있습니다. 사이트의 워터마크 지우기 도구도 직접 찍은 사진의 날짜 도장이나 내 영상에 넣었던 로고를 지우는 용도로 만들었습니다.

  • PDF: 용량 줄이기 · 합치기 · 나누기 · 페이지 정리
  • 변환: 이미지 → PDF · PDF → 이미지
